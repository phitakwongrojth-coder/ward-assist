คำตอบขึ้นอัตโนมัติ (ไม่บังคับ — ต้องมี API key)

ถ้าใส่ Anthropic API key (จาก console.anthropic.com · เสียค่าใช้จ่ายตามการใช้งาน แยกจากค่าสมาชิก Claude) คำตอบจะขึ้นเป็นตัวสีเขียวใต้คำถามเองภายในไม่กี่วินาที · ถ้าเว้นว่าง จะใช้วิธีแตะเพื่อเปิด Claude แทน (ฟรี) · key เก็บไว้ในเครื่องนี้เท่านั้น

วิธีใช้ / ข้อควรระวัง

  1. เปิดใน Safari และกด Allow ไมโครโฟน · เปิด Dictation ไว้ (Settings → General → Keyboard)
  2. ภาษา "ไทย (ปนอังกฤษ)" ถอดได้ดีที่สุดเมื่อพูดไทยเป็นหลัก ศัพท์อังกฤษบางคำอาจออกมาเป็นตัวไทยหรือเพี้ยน — Claude ตีความจากบริบทให้
  3. เมื่อแตะ "ถาม Claude" ระบบจะ Copy คำถามไว้ด้วย ถ้าเปิดแอป Claude แล้วช่องพิมพ์ว่าง ให้กดค้าง → Paste
  4. สลับไปแอป Claude แล้ว iOS จะหยุดฟังชั่วคราว กลับมาแล้วแอปจะฟังต่อเอง
  5. คำตอบจาก AI อาจผิดได้ ใช้ช่วยคิด/ทบทวน ไม่ใช้แทน clinical judgment
  6. ข้อความที่ถอดเสียงอาจถูกประมวลผลบนเซิร์ฟเวอร์ของ Apple และของ Claude — หลีกเลี่ยงการพูดชื่อ/HN ผู้ป่วย และทำตามนโยบายของโรงพยาบาล
